
# Кейс 2: Сплит оплаты (баллы + карта)

## Функциональные требования
1. Максимум баллов = min(баланс, сумма заказа)
2. При успешной оплате → баллы списываются
3. При ошибке оплаты → баллы возвращаются

## Нефункциональные требования
- Время ответа p95 < 700 мс
- Идемпотентность

## SQL схема
```sql
CREATE TABLE loyalty_balance (
    user_id INT PRIMARY KEY,
    points INT NOT NULL DEFAULT 0
);
```
