
# Кейс 1: Процесс возврата товара

## Контекст
Интернет-магазин. Покупатель может вернуть товар надлежащего качества в течение 14 дней.

## Что сделано
- Описан основной процесс возврата
- Выделены 3 основных сценария и 5 граничных случаев
- Написаны acceptance criteria в формате Gherkin

## Acceptance criteria

### Сценарий 1: Успешный возврат

Feature: Возврат товара
  Background:
    Given покупатель авторизован
    And заказ со статусом "Доставлен" создан не более 14 дней назад

  Scenario: Возврат всего заказа в пункт выдачи
    When покупатель инициирует возврат через ЛК
    And выбирает все товары из заказа
    Then система создает заявку на возврат

### Сценарий 2: Просроченный возврат

  Scenario: Возврат после 14 дней
    When покупатель пытается оформить возврат на 15-й день
    Then система показывает сообщение "Срок возврата истек"

## Граничные случаи
1. Товар оплачен баллами + картой → возврат пропорциональный
2. Покупатель не принес товар в ПВЗ за 7 дней → заявка аннулируется

## Выводы
Самое сложное — корректный пересчет сумм при частичном возврате.
