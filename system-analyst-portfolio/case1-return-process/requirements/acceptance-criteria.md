# Acceptance criteria — Возврат товара

## Сценарии в формате Gherkin

Feature: Возврат товара

  Scenario: Успешный возврат
    Given покупатель авторизован
    And заказ доставлен менее 14 дней назад
    When покупатель оформляет возврат
    Then создается заявка на возврат

  Scenario: Отказ при просрочке
    Given с момента доставки прошло 15 дней
    When покупатель пытается оформить возврат
    Then система показывает ошибку "Срок возврата истек"

## Граничные случаи
- Товар по акции "3 по цене 2" → пересчет скидки
- Возврат без чека → запросить номер заказа
