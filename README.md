# system-analyst-portfolio
Мое портфолио учебных кейсов по системному анализу
HR с 7-летним стажем → начинающий системный аналитик. Софт — в крови. Харды — в портфолио. Готова доказать, что границы есть только в голове.🔥
## 🧰 Что я умею

**Требования и спецификации**  
User Stories, функциональные требования, ТЗ, XSD, OpenAPI, сценарии (основные + альтернативы + исключения)

**Моделирование (Draw.io)**  
BPMN (AS-IS → TO-BE), UML (use case, классов, состояний, последовательностей), DDD (поддомены, context map)

**Архитектура**  
Монолит vs микросервисы, горизонтальное масштабирование, шардирование, кеширование

**Данные и базы**  
SQL (SELECT, JOIN, WHERE, GROUP BY), Python (базовый), XML, XSD, JSON

**Интеграции**  
REST (Postman), SOAP

**Инструменты**  
Draw.io, Figma, Jira, Confluence, Git
